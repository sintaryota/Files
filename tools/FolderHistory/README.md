# Folder History

履歴フォルダを自動で表示する、小さな常駐アプリです。Files のサイドバーの「履歴」機能を、単体のアプリとして取り出したものです。

最近使ったフォルダと、よく使うフォルダを、分岐点だけを残したツリーで表示します。**ダブルクリックで、そのフォルダをエクスプローラーで開きます。**

## 使い方

| 操作 | 動作 |
|---|---|
| ダブルクリック / Enter | フォルダをエクスプローラーで開く |
| 右クリック | 「エクスプローラーで開く」「新しいウィンドウで開く」「パスをコピー」「ピン留めに追加 / 外す」 |
| マウスを載せる | フルパスと最終使用日時 |
| F5 / ツールバー「更新」 | すぐに取り込み直す |
| Delete | 選んだピン留めを外す |
| **Ctrl + Alt + H** | どこからでも、ウィンドウを表示 / 非表示（全体で使えるキー） |
| ウィンドウの「×」 | トレイに隠す（アプリは動き続ける） |
| トレイのアイコン | 左クリックで表示 / 非表示、右クリックで「終了」 |

### ツールバー

| ボタン | 動作 |
|---|---|
| 更新 | すぐに取り込み直す |
| 追加… | フォルダを選んで、ピン留めに追加する |
| 既存の窓 | オン（初期）: 開いているエクスプローラーを、そのフォルダへ移動する。開いていなければ新しく開く。オフ: 常に新しいウィンドウで開く |
| 左端 | オン: 画面の左端にマウスを当てると表示し、離れると隠す（初期はオフ） |
| 常に手前 | 他のウィンドウの手前に表示する（初期はオン） |
| 自動起動 | Windows のサインイン時に、トレイだけで起動する（初期はオン） |
| 診断 | 履歴に載った理由、載らなかった理由をテキストで表示する |

### ピン留め

ツリーの一番上の「ピン留め」に、任意のフォルダを **4件まで**登録できます。追加は、ツールバーの「追加…」、右クリック、またはフォルダ（ファイルならそれを含むフォルダ）をウィンドウへドラッグ＆ドロップします。

### 左端の自動表示

「左端」をオンにすると、マウスを画面の左端に当てたまま少し待つと、ウィンドウが左端に出ます。マウスが離れると隠れます。マウスのボタンを押している間や、メニュー、ダイアログが開いている間は隠れません。出ている間は、エクスプローラーの上に重なります。

アプリが動いている間に、ショートカットなどでもう一度起動すると、2つ目は起動せず、動いているウィンドウが手前に出ます。

## 履歴の集め方

- Windows の「最近使った項目」（`%APPDATA%\Microsoft\Windows\Recent`）から、開いたファイルを取り込みます。アプリが終了している間の分も、次の起動時に取り込みます。
- Word の最近使ったファイルを、1分ごとに確認します。
- エクスプローラーでの移動・コピー・名前変更は、Windows に記録が残らないため取り込めません。
- OneDrive や SharePoint のファイル（URL）は対象外です。

表示するフォルダは、最近使った5件と、使用回数の多いものから、最大30件を選びます（履歴は最新の200件を保持）。上位のフォルダは、配下のフォルダが選ばれると隠れます。

親になるのは、**ドライブ直下のフォルダ**です。C: のユーザーフォルダ（`C:\Users\<名前>`）の中は、**ユーザーフォルダの直下のフォルダ**（Downloads、Documents など）が親になります。親の下には、分岐点と、選んだフォルダだけを残します。

ウィンドウがアクティブになったとき（ほかの画面から戻ってきたときなど）は、**最後に使ったフォルダへの経路**と、**エクスプローラーが今表示しているフォルダへの経路**だけを開き、ほかの親をたたみます。そのあいだに手で開いた状態は、次にアクティブになるまで、そのままです。

## データの場所

`%LOCALAPPDATA%\FolderHistory`（`folder_history.json`、`settings.json`、`report.txt`）。履歴は、この端末の中だけで扱い、外部へは送信しません。

## ビルドと配布

.NET 10 SDK が必要です。

```
dotnet build tools/FolderHistory -c Release
```

配布用の exe は、次のコマンドで作ります。

```
dotnet publish tools/FolderHistory -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

`tools\FolderHistory\bin\Release\net10.0-windows\win-x64\publish\FolderHistory.exe` ができます。**動かす端末には、.NET 10 のデスクトップ ランタイムが必要です。**

```
winget install Microsoft.DotNet.DesktopRuntime.10
```
